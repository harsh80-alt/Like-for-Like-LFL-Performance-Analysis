# Like-for-Like (LFL) Performance Analysis: 2026 vs 2025

## Project Overview

This project analyzes retail performance for 2026 versus 2025 using a Like-for-Like (LFL) approach. Instead of comparing calendar dates directly, equivalent trading days were matched to provide a more comparable year-over-year performance view.

## Business Problem

Calendar-date comparisons can be misleading when the number or pattern of trading days differs between periods. The objective of this analysis was to create a comparable performance view by matching equivalent trading days and measuring business growth across different dimensions.

## Tools & Technologies

- Databricks
- SQL
- Power BI
- Delta Lake / Gold Layer

## Key Work Performed

- Matched current-year and previous-year trading days.
- Built the LFL analysis using SQL in Databricks.
- Created Gold-layer tables for Current Year, Previous Year, and LFL comparison.
- Analyzed LFL sales and transaction growth.
- Performed regional and city-level performance analysis.
- Analyzed department-level growth.
- Reviewed monthly performance and momentum.

## Key Insights

- Overall LFL sales growth was **+19.33%**.
- Transaction growth was **+20.90%**.
- West recorded **+21.68%** growth.
- Nagpur recorded **+27.13%** growth.
- Noida recorded **+26.14%** growth.
- Household recorded **+32.38%** growth.
- Monthly growth remained approximately within the **18–22%** range.

## Business Impact

The LFL approach provides a more comparable view of retail performance by controlling for differences in trading days. The analysis showed broad-based growth across regions, cities, departments, and months rather than growth being concentrated in a single area.
